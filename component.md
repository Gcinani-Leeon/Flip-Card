# Flip Card

A 3D flip credit card. The navy front shows a metallic-silver number, a gold EMV chip, a contactless glyph and duo-tone network marks; clicking or pressing Enter rotates it on the Y axis to reveal the magnetic stripe, an Allura signature panel and the CCV.

## Features

- 3D Y-axis flip on a real `<button>` triggered by click and by keyboard (Enter or Space)
- `aria-pressed` reflects the flipped state and the `aria-label` updates to describe the next action
- Pointer-only hover preview — the card lifts and tilts; click, Enter or Space do the flipping
- Mid-flip lift and a settle — the card scales and rises through the turn before landing
- Embossed card number and holder text via layered ink-polarity text-shadows
- Gold EMV chip and a contactless glyph injected from a brand-mark registry
- Duo-tone network discs plus a JetBrains Mono card number, expiry and security code
- Reverse face with a black magnetic stripe, an Allura cursive signature and the CCV block
- Fully respects `prefers-reduced-motion` — the flip still works but resolves instantly

### Border Radius Tokens

**Deliberate identity exception — the card body does not ride the design system's radius scale.**
The component depicts a physical payment card at ISO/IEC 7810 ID-1 proportions (26rem x 16rem). The
1rem body corner (`--fpc-card-radius`) is that standard's 3.18mm die-cut radius reproduced at this
scale, and the 0.6rem face corner (`--fpc-face-radius`) is the tighter moulded corner of the printed
laminate panel that sits on top of it. They are the geometry of the object, not surface styling:
squaring them on an angular system turns the card into a plain rectangle and rounding them on a pill
system turns it into a lozenge — in both cases it stops reading as a credit card. Every element
printed on the card (chip, magstripe, signature panel, CCV box) is drawn against these two corners.

| Token Category | CSS Custom Property                    | Semantic Alias | Used For                                                          |
| -------------- | -------------------------------------- | -------------- | ----------------------------------------------------------------- |
| —              | `--rounded-r9999`                      | —              | Figtree network-mark discs                                        |
| —              | `--fpc-card-radius` (1rem, authored)   | —              | Card body die-cut corner — ISO ID-1 geometry, DS-immune by design |
| —              | `--fpc-face-radius` (0.6rem, authored) | —              | Printed laminate face corner — DS-immune by design                |
| —              | `--cards-radius`                       | —              | Semantic bridge for the card surface radius                       |

## Animations

| Name        | Duration | Easing                              | Element            | Effect                                              |
| ----------- | -------- | ----------------------------------- | ------------------ | --------------------------------------------------- |
| `fpc-flip`  | `0.7s`   | `cubic-bezier(0.3, 0.7, 0.2, 1)`    | `.fpc-card__inner` | Y-axis rotation between the two faces               |
| `fpc-lift`  | `0.7s`   | `cubic-bezier(0.34, 0.65, 0.28, 1)` | `.fpc-card`        | Mid-flip lift — scale and rise through the turn     |
| `fpc-theme` | `0.4s`   | `ease`                              | `body`             | Background and text color crossfade on theme change |

Respects `prefers-reduced-motion: reduce` — all animations and transitions collapse to 0.01ms and the flip resolves instantly.

## Accessibility

| Pattern          | Implementation                                                                 |
| ---------------- | ------------------------------------------------------------------------------ |
| Flip control     | The whole card is a native `<button>` — click, Enter and Space all flip it     |
| State exposure   | `aria-pressed` tracks the flipped state                                        |
| Action label     | `aria-label` updates to describe which face the next activation reveals        |
| Decorative art   | Logo, chip, contactless glyph and duo-tone network marks are `aria-hidden`     |
| Focus indicators | `:focus-visible` with the `--ring` outline on the flip button                  |
| Reduced motion   | `prefers-reduced-motion: reduce` makes the flip instant while still functional |

## Known Limitations

- The card data (number, holder, expiry, CCV) is illustrative and hardcoded in the markup
- Hover lift and tilt are pointer-only enhancements and do not change the `aria-pressed` state
- Brand marks are injected by JavaScript, so they do not render if scripting is disabled

## Customization

- **Card data**: Edit the number groups, holder, expiry and CCV in `index.html`
- **Palette**: Adjust the card color keys in `design-systems/flip-card/DESIGN.md`
- **Flip speed**: Change the `transition` duration on `.fpc-card__inner`
- **Design system**: Run `npx tsx apply-design.ts flip-card payment/flip-card` to re-theme
